# 冻结C-low观测退化校准

本实验从提交39645b9继承六个step1800 C-low和两个任务各20个development状态。不运行D，不训练，不生成AE标签。

`prepare.py`固定协议、身份和哈希划分，使用每任务第一条数字ID训练示范的5个等距时刻输出双相机图像。人工信息保留检查必须先保存`image_acceptance/manual_review.json`。图像均为方向修正后的224×224输入。

`transforms.py`在原Prismatic图像处理器的resize→center_crop→float32张量之后、每个视觉主干normalize之前施加一次扰动。两个主干几何必须逐元素相同；同一扰动图像用于各自normalize，不重复加噪。Clean不进行额外重编码。噪声采用PCG64，seed为固定前缀、完整任务名、物理初态内容SHA、控制步、相机名的SHA256前16字节（大端整数）；不包含策略seed或强度。不同强度只改变缩放。裁剪为floor尺寸、floor中心偏移、双线性antialias=True，K采用half-pixel缩放公式，负fx保持。

`evaluation.py`对前轮已验收的真实闭环函数进行带断言的有限适配，并保存有效源码。只用Clean XML；在线相机图像进入新处理器；语言、proprio、动作解码、控制及成功判定不变。评分前每任务3模型各做原/新Clean推理一次，共12次验收前向，保护全部RNG。视频记录原始Clean在线渲染，不冒充扰动后输入视频；输入可由冻结键和代码重建。

`orchestrate.py`串行执行完整单因素、符合门槛的唯一组合、唯一候选复核。所有任务完成单因素后才选择；顺序为模糊→噪声→裁剪，各家族最低达标强度。组合需九项全通过且均≥60%。目标40%≤均值<60%，否则不插值，不添加条件。技术故障保留并停止，不重跑有效失败。

运行需设置`RLA_PROJECT_ROOT`、`OBS_CAL_ROOT`，沿用项目隔离Python环境；评分前保存protocol_commit.json并提交冻结协议。`analyze.py`生成完整强度曲线、每seed结果、配对翻转和以10个物理状态为单位的区间。`publish.py`仅发布脱敏小型材料。

这些状态全部曾参与开发；本轮复核不是独立测试。低于60%是样本难度目标，不证明总体低于60%。结果不能证明增强可解决或一致性有效。禁止自动追加训练或搜索。
