# 唯一优先后续实验：延长 LR×0.1 的 C / D-center 匹配对照

本文件是建议，本轮未执行。

## 问题与依据

检验较低策略 LR 下仍在改善的两组，是否在更长但固定的预算下继续学习，并保留分项动作能力。不是重新搜索辅助损失权重，也不是验证 AE 一致性已经有效。

200步固定development的Clean/Background动作L1：C×0.1为0.19936/0.19548，D-center×0.1为0.19733/0.19645；两组相近，100→200步均继续改善。当前有效曝光仅约0.626个训练窗口池遍历，不能声称充分训练。较高LR的实际参数移动更大、200步动作误差更高，但也尚未证明其最终收敛更差。

此前把λ_aux降至0.1倍令C由59/60降至5/60，不能简单重复“继续降低辅助权重”的建议。局部梯度诊断不支持仅凭负余弦或target尺度就决定新loss。AE-D已有尺度收缩和轻微重建代价，但本轮没有识别AE λ_inv或AE seed的因果作用。

## 冻结方案

- 仅选择C×0.1与D-center×0.1，两组共同将有效预算延长到600；不增加LR候选、seed或任务。
- 唯一主要改变是终止更新数200→600。维持本轮原1200步MultiStepLR定义、base LR2e-4×0.1、原λ_aux、target中心和共同缩放、数据、batch、数值后端与采样。
- 从各自完整恢复状态继续，不从已训练C初始化D。C已有完整400步状态可复用，D用200步状态；先核验共同采样前缀、scheduler与RNG连续性。C在中断前已记录但未持久化的401–416步，若重放必须单列16次实际计算，不能当新增有效预算或隐去成本。
- 固定保存/评估400与600，主模型统一600。既有200节点保留。不得按development曲线追加预算或换checkpoint。
- 继续报告逐维、当前/远期chunk、每示范及可靠抬升前后误差；监控非有限数值、夹爪和远期动作恶化。保持原停止条件，不启用梯度隔离或裁剪。
- 如果模型与恢复验收通过、动作数值/部署接口无异常，下一轮再授权有限的匹配development闭环：同一预冻结状态与外观、固定步数和成功判定，两组均评估，失败也保留。离线L1不作为“D已恢复”或选择有利状态的依据。

## 边界

该实验只能检验固定AE、同seed下的策略早期预算不足假设。不能回答AE训练是否充分、AE一致性权重是否最优或多seed泛化；development结果不是独立测试。本轮没有自动执行延长训练或任何闭环。
