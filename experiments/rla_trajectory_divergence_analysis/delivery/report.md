# C 与共享 Clean target 的已有配对轨迹分析

计划 **200 对**，实际有效 **200 对 / 400 条轨迹**：Clean 40 对，新背景 160 对；无缺失、无损坏、无排除。状态与字段验收通过；机制结论仍为 **PARTIAL**。

发现一个值得有限验证的**局部候选模式**：顺序 20261102 的共享 target 经常在抬升后发生“接触盘但水平未居中”，且在终局超时之前已出现；顺序 20261101 不重复这一失败模式。它能描述第二个顺序的后半段执行缺口，不能证明辅助监督、夹爪、旋转或 chunk 是根因。保持两个负结果实现停止调参。

唯一优先建议：如决定继续，预先固定少量顺序 20261102 Clean 状态，做一次**同一完整抬升后快照下仅切换续跑策略 C/shared 的有界因果诊断**；先通过原策略续跑恢复验收，否则结束诊断。当前不执行，不修改任何方法，不追加梯度分析。

## 2. 字段与时间轴

实际执行代码依据：`experiments/rla_lr_budget_sweep/extend_evaluation.py:63–109`；阶段代理依据 `experiments/official_libero_rla_consistency/stove_postlift/common.py:24–34`。只读源码，不导入仿真模块。

- 400/400 数组长度、维度、有限性、phase 控制步编号通过。每个 NPZ 包含执行动作 N×7、预测 ceil(N/8)×8×7、N×92 仿真状态、N×3 末端与碗位置。
- `predicted_chunks` 是反归一化后的动作预测；平移/旋转分量逐元素传给控制器；夹爪转换为 `-sign(2*g-1)`，执行 +1 闭合、−1 打开。全部 400 条执行命令与预测展开及此后处理逐元素一致，无遗漏 chunk 或错位证据。
- 平移/旋转动作是 OSC_POSE 控制命令，不是实际米位移或测量姿态角误差。本轮不把旋转命令差转换成真实角误差，也不猜控制器物理缩放。
- `states/eef_positions/target_bowl_positions/phase` 均在动作执行后采样。控制步 1 对应第一条动作后的状态。末端记录与 phase 坐标一致；碗 body/geometry 中心在这批记录上差值为零。
- 视频 2.5 fps，每 8 个 20 Hz 控制步、推理前记录一帧；视频帧 k 对应下一动作前控制位置 8k。最后视频帧未必包含终局状态。
- 首个预测 chunk 可以比较同初始物理状态和同外观下输出；其第2–8个预测动作并非读取同一组真实未来观测。后续动作差同时包含策略与各自已分化的输入状态。
- 提前成功轨迹保留原长度；控制步配对仅取双方真实公共前缀，不延长、不补齐；各自完整曲线及首次抬升相对时间曲线另外保留。无时间拉伸。
- 原任务标签保持原 `env.check_success()`；记录的 goal 与 height、contact、XY<3cm 三条件组合逐步一致。接近≤10cm、抬升≥3cm是历史描述性代理，不是抓取真值。部分成功轨迹未跨过3cm抬升阈值，不能据此改判失败。

在查看分组曲线前冻结：末端分离主阈值3cm、敏感性5cm，连续8控制步；3cm沿用目标水平居中尺度，8步为一chunk。它们只定义位置差异，不定义失败。

**200/200 对**都出现连续8步超过3cm的位置分离，**191/200 对**超过5cm。双方成功组的92对全部超过3cm，其中83对超过5cm。因此“早期分离”本身没有失败特异性。

顺序20261101双方成功组，首次持续3cm分离中位控制步13，shared抬升相对C中位晚5步；C成功/shared失败组首次分离中位14.5步。正常路径/速度变化足以产生明显动作与位置差。

顺序20261102各结果组首次3cm分离中位约11–12步。双方都有抬升事件时，C-only组shared抬升中位晚33步；双方成功组反而中位晚57步，shared-only组晚58步。**“更晚抬升”不能单独解释失败**，事件缺失不强行匹配。

## 4. 候选模式、反例和边界

### 4.1 顺序20261101：少数失败集中于未跨过抬升代理

4对 C成功/shared失败中，shared 4/4 未达到3cm抬升代理，历史分类均为接近后抓取/接触失败；不是“抬升后放置退化”。此外1对双方失败的shared也无抬升事件。该顺序shared仍有95/100成功，不能用第二顺序的后半段模式解释它。

### 4.2 顺序20261102：抬升后接触但未居中的局部重复现象

操作性定义：已有3cm抬升事件之后、终局之前，phase记录 `contact_condition=true && xy_condition=false`。无新增距离阈值、无接触力或稳定抓持推断。

|结果组|配对数|C出现该事件|shared出现该事件|
|---|---:|---:|---:|
|双方成功|3|0|0|
|C成功/shared失败|63|7|43|
|C失败/shared成功|8|0|0|
|双方失败|26|11|20|

在63对C成功/shared失败中，shared有46条达到抬升代理，43条在超时前出现上述离心接触；首次事件中位控制步158（上限220），全组该状态持续时长中位50控制步。其终局有60/63接触盘，但仅2/63水平居中、37/63满足高度，说明**接触不等于完整放置**。

双方失败组shared的20条抬升轨迹均出现离心接触，首次中位149.5步；此现象不是C-only组专属。双方成功或shared-only的11条shared成功轨迹无此事件，提供同顺序反例。

该事件也并非“必然失败”：顺序20261101双方成功的89对中，C和shared各1条短暂出现离心接触后成功；其双方失败组C也出现。因此本轮只识别**局部、顺序依赖的放置对齐候选问题**，不指定首次失败时刻或唯一物理原因。

每个出现状态、外观和顺序见 `recorded_condition_summary.csv`，所有分母见组表。背景2属于既有观察后受到关注的条件，不构成独立确认性证据。

### 4.3 不支持的解释

- 抬升后在目标外首次松爪：400条均未触发冻结定义，不能归咎“普遍提前松爪”。不代表不存在其他夹爪/抓持问题。
- 手指接触丢失事件很少，双方成功中也有；仅几何接触不能确认滑落、握持力或稳定抓持。
- “曾居中后失去居中”在顺序20261101双方成功的shared中19/89，而其4条C-only失败中0/4；不具通用失败特异性。
- 主规则和敏感性规则下，连续8个下降区间累计外移≥3/5cm均0条。**只能说明该严格持续下降模式未被检出，不能说不存在间歇外移**；连续原曲线保留，不为获得阳性结果改规则。
- 重新接近仅按末端—碗10cm阈值的 near→far→near 计数。它不是重新抓取或恢复任务的证据，阈值附近往返也可能触发。
- chunk边界动作跳变高于内部在两模型、两个顺序均可见。顺序20261102共享target的边界平移命令平均跳变约0.076，C约0.082；并不支持“shared边界跳变更大”这一简单解释。命令差无物理位移单位，比较并未匹配后续观测。
- 现存闭环记录不能解释训练数据覆盖，**数据覆盖原因未验证**。没有证明长期控制退化源自梯度冲突、表示坍塌、缺恢复数据或8步开环chunk。

## 6. 判断与唯一后续建议

属于**局部候选模式存在、因果机制未确定**。不同路径和较慢抬升通常也能成功；顺序20261102额外呈现重复的抬升后水平对齐缺口。无法据此确认是前缀抓持状态、后半段策略能力还是二者交互，不能支持直接改loss、夹爪阈值、chunk或采样。

唯一可考虑的有限验证（本轮不执行）：在顺序20261102 Clean前4个固定development状态、不按成败选状态，分别保存已有抬升事件后的首个chunk边界完整运行状态；每个前缀只改变后续策略身份C/shared，剩余预算相同，清空待执行chunk。最多8前缀和16续跑，先验收同策略恢复的轨迹与终点一致。若无法恢复控制器、观测历史和仿真状态，或没有合法抬升快照，该单元缺失，不另挑状态/加预算；恢复不可靠则结束当前炉灶诊断。此实验只检验后半段策略/前缀状态交互，不训练，不改变动作，不将C视为专家。

不自动执行该方案。不解除D-center/shared-target停止调参决定。所有结果仅限单任务、两个采样顺序、反复用于开发的20个物理状态；100个状态×外观行并非100个独立初始状态，两个顺序也不是完整训练seed复核。本轮给描述性计数而非独立样本显著性或泛化区间。
