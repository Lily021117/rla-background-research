# 视觉变化量与边界

RGB误差采用0–255通道数值的平均绝对差，不是归一化模型误差。完整序列两相机数据见visual_summary.csv；固定小样的实际目标GEOM区域见sample_region_summary.csv。

碗对象1/2在小样目标区域的MAE分别约14.91/13.62（agentview）、18.77/17.20（wrist）。抽屉对象1分别约10.43/11.76；对象2仅约1.07/1.92。**抽屉对象2相对Clean较弱**，不能将四种干预描述为同等强度；它与对象1有明显数值差别，未因为预期策略效果而加重或替换。目标很小时，全图MAE较低，不代表参数没有作用。

完整序列光强干预全图MAE约12.8–15.5；方向干预约8.9–30.1，因任务与相机不同而不同。它们不是对象局部干预。小样所有条件深度最大差0、GEOM实例分割一致。

全程图像有效性检查通过，不等于目标/夹爪在所有时刻均无遮挡。物理状态、材质修改白名单与相机匹配是配对依据；本轮没有策略可学习性或难度结论，也未测开放环源动作复现。
