## 配置与边界

AE从官方step90000共同初始化，重建=两外观各自L1+MSE平均，一致性=16×64 latent均方差，h1..8、AdamW1e-4、固定loss scale256，DINO冻结。新AE采样4800物理转移与历史逐项一致。不是从已训练D继续。

策略直接复用历史stove_centering训练入口及原始共同step0；除新AE target及其训练集自身均值外，保留共同s_C、lambda_aux、Math BF16、checkpointing、STOP/mask、batch16、optimizer与LR。scheduler在每次optimizer.step后调用，600次update都用2e-4；600步checkpoint保存的LR2e-5是最后scheduler调用后的值，不是第600次实际LR。

新sidecar保留内部D目录别名，但指向本次D-inv03 encoder，不是历史D。训练均值为20条train、两外观、完整有效窗口全部8跨度的FP32输出/FP64累加；development不参与拟合。读取与源RGB重算检查见target_readiness。真实未来仅作为target生成与监督，不作为策略推理条件。

本次使用GPU0，历史AE/策略存在GPU1、GPU0与中断恢复差异；保留历史证据，不能声称跨设备路径逐位相同。共同初始参数、数据与RNG按实际入口核验，设备差异单列，不静默改变优化配置。

20个development状态已反复用于探索与调参，单seed。配对bootstrap以物理状态为聚类单位，三外观联合重采样；零翻转或极少翻转导致离散/退化区间，不代表确定等价或稳定泛化。未见背景并未用于AE/策略训练。

latent距离、均值、尺度、有效秩及重建需一起解释：尺度缩小不等于不变性改善，有效秩降低不直接叫坍塌。重建不是动作条件前向预测。结果不触发追加lambda、LR、seed、任务或训练步数。

## 主要结论

1. **相对原 D-center，完整任务能力没有恢复。** D-inv03 三种外观均为 0/20，与原 D-center 的逐状态成功标签完全相同。没有成功翻转。0→0 是地板效应，不是鲁棒性良好，也不是证明两个策略等价。
2. **相对原 C，仍有明显控制代价。** 原 C 为 20/20、19/20、20/20；新组为 0/20、0/20、0/20。三外观等权差为 −98.33 个百分点，状态聚类 bootstrap 95% 区间 [−100,−95] 个百分点；逐条件负翻转为 20、19、20，无正翻转。这是本批调参 development 状态上的描述，不是独立泛化结论。
3. **仍保留相对 AE-C 的跨外观表示稳定性改善，但弱于原 AE-D。** Relative L2：C 0.43559、原 D 0.24063、新组 0.27854；单位范数 L2：0.43462、0.24060、0.27852。新组的改善并非完全由整体尺度缩小解释，但不能据此声称任务语义更好。
4. **未见背景没有改善。** 新组仍为 0/20。其对 C 的已见背景交互项为 +5pp，但来自 C 的 20→19 与新组 0→0，不能解释成鲁棒性收益；未见交互为 0。每个新组 0/20 的 Wilson 95% 上界约 16.1%，不是总体成功概率已被证明为零。全零配对 bootstrap 的 [0,0] 区间仅反映经验样本退化。

## 表示、重建与尺度取舍

固定 5 条 development 示范、400 个 anchor/horizon 转移，双相机、双外观，历史与新组样本清单逐项一致。两相机及两外观等权重建 L1：C 0.049867、原 D 0.050924、新组 0.050473；新组相对 C 约增加 1.21%，相对原 D 约下降 0.89%。复制当前 tokens 的参照 L1 为 0.081638。Decoder 可利用当前特征，因此这些结果不独立证明真实运动信息完整保留。

Clean latent norm：C 85.893、原 D 36.136、新组 46.388；逐维方差均值：2.380、0.282、0.513；entropy effective rank：72.407、43.954、50.968。Background 同方向（新组 norm 46.339、有效秩 50.954）。减弱约束缓解了部分尺度/维度压缩，但未恢复到 C；不能把有效秩较低直接判为坍塌。均值、逐相机/跨度误差、不同 episode 距离和 decoder zero/wrong-latent 对照在 CSV 中保留。

本轮唯一主动训练配置干预为 AE lambda_inv 从 0.009127798272072366 降至 0.0027383394816217098。新 AE 造成 target 分布及其训练均值变化是派生结果；共同策略 lambda_aux 不保证辅助梯度强度完全相同，因此不能把观察到的所有差别都直接归因于“表示不变性”。

## 失败阶段与离线误差

60/60 次均发出关闭命令，60/60 次达到原有 3cm 抬升诊断阈值，60/60 次归为抬升后/放置失败。此阈值仅用于诊断，不替代官方成功条件。

按 Clean／已见／未见背景，抬升后曾满足盘接触条件的次数为 10/20、13/20、12/20；曾满足水平居中条件为 1/20、0/20、2/20；接触、高度、水平条件同时满足为 0/20、0/20、0/20。抬升后未记录到打开命令，不能由此断言物体始终被稳固抓持。最终平均水平误差为 16.91cm、16.09cm、16.50cm；下降区间累计水平路径为 29.32cm、27.74cm、29.34cm（路径长度，不是单次净漂移）。这支持“后半段任务条件未完成”，不单凭这些指标指定唯一物理原因。

新策略归一化 action L1：step0 Clean/Background 0.52339/0.50983，step600 0.20884/0.20825。step600 平移约 0.19379/0.19384、旋转 0.26443/0.26331、夹爪 0.08723/0.08634。旋转误差较 step300 的约 0.236/0.236 回升；总 L1 下降仍未转化为完整任务成功。各维度为训练归一化坐标，不能称为米或弧度的物理误差。

历史 C/D-center 缺少本轮部分细粒度遥测，相关字段明确标为缺失，未当作零值，也未新增历史闭环补测。低 LR 两组另列：C 为 20/19/1，D-center 为 19/16/0（各分母20）。它们实际 update LR 是 2e-5、沿用1200步 scheduler，不能与本轮 2e-4 历史600步曲线混为严格单变量比较。
